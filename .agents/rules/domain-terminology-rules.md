# Domain Terminology & Acronyms

## Rule
In this repository and all user prompts, the acronym **GBBO** refers to **The Great British Bake Off** (British television baking competition series, broadcast as *The Great British Baking Show* in North America).

## Guidelines
1. **Domain Meaning**:
   - Always interpret `GBBO` (or `gbbo`) in all prompts, issues, and code contexts as referring exclusively to **The Great British Bake Off**.
2. **Naming Conventions**:
   - Primary CLI and scripts: `scripts/scrape.py`, `scripts/build.py`, `scripts/models.py`.
   - Data files and tables: `bakers.json`, `episodes.json`, `performances.json` (and `*.csv`).
3. **Common GBBO Domain Acronyms & Terms**:
   - **GBBO**: The Great British Bake Off
   - **GBBS**: The Great British Baking Show (North American broadcast title)
   - **SB**: Star Baker (awarded to standout baker each episode)
   - **SIG**: Signature Challenge
   - **TECH**: Technical Challenge
   - **SHOW**: Showstopper Challenge
   - **HH**: Hollywood Handshake (praise gesture from judge Paul Hollywood)
   - **OUT**: Eliminated baker
